# LEGO Control

An interactive, responsive front-end demo for controlling a LEGO railway layout. The demo combines the supplied Railway, Lighting, and Switches design references into one dependency-free web application.

## Run locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

The controls are simulated in the browser: change train speed and direction, stop the train, switch lighting circuits, adjust brightness, and move points. Use **Reset demo** to restore the initial state.
